# Gemini Agent Workspace

Claude-like Gemini Agent UI using the Google Gemini Interactions API and Antigravity managed agent.

## Highlights
- Real agent tool/activity stream with command/result details when provided by the API.
- Automatic `/workspace/outputs` polling: generated deliverables appear without clicking Refresh outputs.
- Claude-style output cards: filename, file type, Download.
- Markdown rendering for headings, bold, italics, code, lists and more.
- Change summary from `git diff --numstat` with `+insertions` and `-deletions`.
- Persistent sandbox continuation, background execution and recovery.
